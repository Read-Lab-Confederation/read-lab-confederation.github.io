New Publication: camlhmp, a framework for reproducible microbial genome-based typing tools

April 20, 2026

Robert Petit and Tim Read have published “camlhmp: a simple framework for building reproducible microbial genome-based typing tools” in Microbiology Resource Announcements. camlhmp (Classification through yAML Heuristic Mapping Protocol) provides a straightforward way to define and maintain organism typing schemas using YAML, making it easier to build consistent and reproducible typing tools for microbial genomics.
